# GDELT News

Display name: **GDELT News**, part of FIN TERMINAL.

## Brief

Bloomberg-style global news dashboard fed by the GDELT feed (package `gdelt-news-terminal`, build name `GDELTNews`, port 8029). Formerly `src/news`.

Upstream data docs: https://www.gdeltproject.org/data.html (not a repository).

## FOSS references

Existence of each repository checked with `git ls-remote` on 2026-10-29. Licences as published upstream; re-check before reuse.

- [linwoodc3/gdeltPyR](https://github.com/linwoodc3/gdeltPyR): Python framework to retrieve and analyse GDELT data (GPL-3.0)
- [alex9smith/gdelt-doc-api](https://github.com/alex9smith/gdelt-doc-api): Python client for the GDELT DOC 2.0 API (MIT)
- [OpenBB-finance/OpenBB](https://github.com/OpenBB-finance/OpenBB): Terminal with news providers, comparable scope (AGPL-3.0)
- [pydata/pandas-datareader](https://github.com/pydata/pandas-datareader): Data readers for pandas (BSD-3-Clause)
- [scikit-learn/scikit-learn](https://github.com/scikit-learn/scikit-learn): Classification and clustering for news topics (BSD-3-Clause)
- [AI4Finance-Foundation/FinGPT](https://github.com/AI4Finance-Foundation/FinGPT): Financial LLMs, news sentiment (MIT)

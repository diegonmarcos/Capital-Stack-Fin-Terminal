## Brief

Central-bank data and policy tooling (rates, balance sheets, monetary series). The code is not in this repo: it lives in Fin-CM-mqpm [`src/central_bank`](https://github.com/diegonmarcos/Fin-CM-mqpm/tree/main/src/central_bank) (moved there with history by #1218). ## FOSS references

Existence of each repository checked with `git ls-remote` on 2026-10-29. Licences as published upstream; re-check before reuse.

- [mortada/fredapi](https://github.com/mortada/fredapi): Python client for the FRED and ALFRED economic data API (Apache-2.0)
- [khaeru/sdmx](https://github.com/khaeru/sdmx): Python SDMX client/model, reaches ECB, BIS, IMF, OECD, Eurostat (Apache-2.0)
- [dr-leo/pandaSDMX](https://github.com/dr-leo/pandaSDMX): Earlier pandas-oriented SDMX client (predecessor of sdmx) (Apache-2.0)
- [pydata/pandas-datareader](https://github.com/pydata/pandas-datareader): Remote data access for pandas (FRED, World Bank, OECD and others) (BSD-3-Clause)
- [OpenBB-finance/OpenBB](https://github.com/OpenBB-finance/OpenBB): Open data platform with macro and central-bank data providers (AGPL-3.0)
- [polakowo/vectorbt](https://github.com/polakowo/vectorbt): Vectorised backtesting, usable on rate and macro series (Apache-2.0 with Commons Clause)
